# Open Book Investor Guide

Standalone review prototype for Mia Shlomit Gordon's rental-property investor experience.

This repository is intentionally separate from the production portfolio site.

## Structure
- `index.html` — guided investor experience and portfolio ledger
- `assets/artemis-mark.svg` — Open Book brand mark copied from the production site's assets
- `assets/artemis-favicon.svg` — production favicon asset
- `assets/live/refined-theme.css` — snapshot of the production portfolio theme for shared visual reference
- `assets/live/property-page-theme.css` — snapshot of the production property-page theme
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow

The current property-detail links continue to point to the production property pages so reviewers can inspect the real available-property pages without duplicating those assets here.
